# Traffic Sign Quiz

This project is from my Client Side Web Development Module in Year 3 Semester 1. A browser-based quiz for learning Irish road traffic signs. The application includes account sign-up and login, a 10-question timed quiz, pass/fail results, answer review, and a history of previous attempts.

## Features

- Create an account and log in with an email address and password
- Answer 10 multiple-choice traffic sign questions
- Navigate between questions before submitting
- Complete the quiz within 3 minutes
- Receive a pass at 8/10 or higher
- Review the correct answers for missed questions
- Retry the quiz
- View past results and attempt scores

## Pages

- `login.html` - account creation and login
- `quiz.html` - timed quiz and answer review
- `results.html` - past quiz results
- `attempts.html` - detailed previous attempts

## Run the Project

The project is a static website and can be opened directly in a browser.

1. Open `login.html` in your browser.
2. Create an account.
3. Log in to begin the quiz.


## Data Storage

User accounts, quiz attempts, scores, and the currently logged-in user are stored in the browser's `localStorage`. Data is specific to the browser and domain used to access the site.
